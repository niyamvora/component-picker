Copy any component as an AI-ready bundle.

Hover, click, paste. HTML, browser-resolved CSS, interaction states, themes, tokens, animations and responsive diffs — everything an AI needs to rebuild it pixel-perfect.

Download GitHub →

What it captures

Resolved CSSReal px/rgb values diffed against browser defaults — not a flat DOM dump.
States & themesForced :hover/:focus/:active and the other colour theme, as diffs.
Tokens & TailwindEvery var(--…) named and resolved; optional Tailwind and W3C token JSON.
AnimationsRunning WAAPI/CSS animations, Framer Motion props, GSAP timelines.
Components, not soupMaps onto your own <Button>/<Card>; repeats collapse to one + data.
AccessibilityRoles, names, WCAG contrast and focus order — nobody else captures it.

Install

npm install && npm run build   # or download the release zip
chrome://extensions → Developer mode → Load unpacked → dist/

Privacy: everything runs locally in your browser. No network calls, no analytics, no account. The one exception — the optional MCP bridge — is off by default and localhost-only.
